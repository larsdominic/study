SL 1.1Scientific notation
a × 10k with 1 ≤ a < 10 and k an integer. Calculator notation such as 5.2E30 scores nothing.
Example: 0.000 340 2 = 3.402 × 10−4
SL 1.2Finding d and counting terms
d = u2 − u1. With technology the IB still expects you to state the first term and d.
Example: 7, 11, 15, … has d = 4, so u20 = 7 + 19 × 4 = 83.
SL 1.2, 1.3A term from the sum formula
un = Sn − Sn−1 (and u1 = S1).
Example: If Sn = n2 + 3n, then u5 = S5 − S4 = 40 − 28 = 12.
SL 1.2, 1.3Sigma notation
Substitute each whole number from the bottom value to the top value and add. Number of terms = top − bottom + 1.
Example: 4Σk=1(2k + 1) = 3 + 5 + 7 + 9 = 24.
SL 1.3Finding the common ratio
r = u2u1 (any term divided by the one before).
Example: 48, 12, 3, … has r = 1248 = 14.
SL 1.8Why the infinite sum exists: say it
The booklet prints the condition, but in a "justify" or "explain" part you must write it in words and numbers: "the sum exists because |r| < 1". If r contains x, solve −1 < r < 1.
Example: |r| = ¼ < 1, so S∞ = 481 − ¼ = 64. If r = 2x3, the sum exists for −32 < x < 32.
SL 1.4Depreciation
Value falls by r% a year: value = PV × (1 − r/100)n. Not printed in this form; on the GDC finance app use a negative I%.
Example: A $20 000 car losing 15% a year is worth 20 000 × 0.853 = $12 282.50 after 3 years.
SL 1.4Real value with inflation
IB mark schemes usually take the real rate as interest rate minus inflation rate and use that as I%.
Example: $5000 at 4% a year with 2% inflation for 5 years: real rate 2%, 5000 × 1.025 = $5520.40 in today's money.
SL 1.5Laws of exponents
am × an = am+n, am ÷ an = am−n, (am)n = amn, a−n = 1an, a0 = 1.
Example: 53 × 5−6 = 5−3, (2x)4 = 16x4.
SL 1.5ln means base e
logex = ln x, and log with no base means base 10. You can only take the log of a positive number.
Example: ln e3 = 3, log 1000 = 3.
SL 1.7Fractional exponents
a1/m = the mth root of a (the positive root when m is even); ap/m = (mth root of a)p.
Example: 163/4 = (4th root of 16)3 = 23 = 8.
SL 1.7Solving exponential equations
Take ln (or log) of both sides, bring the power down with the third log law, then solve.
Example: 2x−1 = 10 gives x − 1 = ln 10ln 2, so x ≈ 4.32.
SL 1.6Proof layout (LHS to RHS)
Start from one side only, change it step by step, end with "= RHS". Use ≡ for an identity (true for every x). Never work on both sides at once.
Example: LHS = (x − 3)2 + 5 = x2 − 6x + 9 + 5 = x2 − 6x + 14 = RHS.
SL 1.9Pascal's triangle and picking out one term
Row 5 is 1, 5, 10, 10, 5, 1. The term with br uses nCr, which is the (r + 1)th term. Keep the coefficient inside the bracket when you raise it to a power.
Example: Coefficient of x3 in (2 + x)5: 5C3 × 22 = 10 × 4 = 40.

SL 2.1Parallel and perpendicular lines
Parallel: m1 = m2. Perpendicular: m1 × m2 = −1 (negative reciprocal).
Example: A line perpendicular to y = 2x + 1 has gradient −12.
SL 2.2Domain, range and inverse
Domain = allowed x values, range = output values. An inverse exists only for a one-to-one function; the domain of f −1 is the range of f; its graph is the reflection in y = x.
Example: f(x) = √2 − x has domain x ≤ 2 and range f(x) ≥ 0.
SL 2.5Composite and inverse functions
(f ∘ g)(x) = f(g(x)): apply g first. To find f −1: write y = f(x), swap x and y, make y the subject. (f ∘ f −1)(x) = x.
Example: f(x) = 2x + 1, g(x) = x2: (f ∘ g)(3) = f(9) = 19; f −1(x) = x − 12.
SL 2.6The three forms of a quadratic
y-intercept (0, c). a(x − p)(x − q): x-intercepts p and q. a(x − h)2 + k: vertex (h, k). Watch the sign of h.
Example: 2(x − 3)2 + 1 has vertex (3, 1); x2 + 6x + 5 = (x + 3)2 − 4 has vertex (−3, −4).
SL 2.7What the discriminant tells you
Δ > 0: two distinct real roots. Δ = 0: two equal real roots (one repeated root). Δ < 0: no real roots. "Real roots" (not distinct) means Δ ≥ 0.
Example: x2 + 4x + k = 0 has equal roots when 16 − 4k = 0, so k = 4.
SL 2.7Quadratic inequalities
Solve the equation first, sketch the parabola, then read off where it is above or below the axis.
Example: x2 − x − 6 < 0 ⇒ (x − 3)(x + 2) < 0 ⇒ −2 < x < 3.
SL 2.8Asymptotes of a rational function
For ax + bcx + d: vertical x = −dc, horizontal y = ac. y = 1x is its own inverse.
Example: f(x) = 2x + 1x − 3 has asymptotes x = 3 and y = 2.
SL 2.9Exponential and log graphs
y = ax passes through (0, 1) with asymptote y = 0; y = logax passes through (1, 0) with asymptote x = 0 and needs x > 0. They are inverses (reflections in y = x).
Example: y = ln(x − 2) is defined only for x > 2 and has asymptote x = 2.
SL 2.10Hidden quadratics
Spot a2x = (ax)2, factorise, then solve each bracket. When no algebra works, use the GDC.
Example: e2x − 5ex + 4 = 0 ⇒ (ex − 1)(ex − 4) = 0 ⇒ x = 0 or x = ln 4.
SL 2.11Transformations
f(x) + b up b; f(x − a) right a; −f(x) reflect in the x-axis; f(−x) reflect in the y-axis; p f(x) vertical stretch, factor p; f(qx) horizontal stretch, factor 1q. Order matters.
Example: From y = x2 to y = 3x2 + 2: vertical stretch factor 3, then translate up 2.

SL 3.2Right-angled triangles
Pythagoras a2 + b2 = c2 and SOH CAH TOA: sin = opp/hyp, cos = adj/hyp, tan = opp/adj.
Example: Hypotenuse 10, angle 30°: opposite side = 10 sin 30° = 5.
SL 3.1Hemispheres and total surface areas
Only curved surfaces are printed. Add the flat faces yourself. A hemisphere is half a sphere: V = 23πr3, a solid one has A = 2πr2 + πr2 = 3πr2.
Example: Solid cone, r = 3, l = 5: 15π + 9π = 24π ≈ 75.4. Hemisphere, r = 3: V = 18π ≈ 56.5.
SL 3.1Angle between a line and a plane
Drop a perpendicular from the line to the plane; the angle is in the right-angled triangle formed by the line and its shadow (projection) on the plane.
Example: Box 3 by 4 by 12: base diagonal 5, angle of the space diagonal with the base = tan−1(12/5) ≈ 67.4°.
SL 3.3Bearings, elevation, depression
Bearings: clockwise from north, three figures (045°). Elevation and depression are measured from the horizontal.
Example: From 64.3 m away, a 30 m tower has elevation tan−1(30/64.3) ≈ 25°.
SL 3.4Radians
π rad = 180°. Arc and sector formulas only work in radians. Area of a segment = sector − triangle = 12r2θ − 12r2 sin θ.
Example: 60° = π3. Segment with r = 6, θ = π/3: 6π − 9√3 ≈ 3.26.
SL 3.5Exact values
sin: 0, ½, √2/2, √3/2, 1 for 0, π/6, π/4, π/3, π/2. cos: the same list backwards. tan: 0, √3/3, 1, √3, undefined.
Example: sin(π/3) = √3/2, cos(3π/4) = −√2/2, tan 210° = √3/3.
SL 3.5Unit circle and quadrants
A point on the unit circle is (cos θ, sin θ). Positive in quadrants 1 to 4: all, sin, tan, cos. Symmetries: sin(π − θ) = sin θ, cos(−x) = cos x, sin(π + x) = −sin x.
Example: The line through the origin at angle θ to the positive x-axis is y = x tan θ.
SL 3.5Ambiguous case of the sine rule
Given two sides and an angle not between them, sin B gives two angles, B and 180° − B. Keep both if the angles still add to less than 180°.
Example: A = 30°, a = 6, b = 10: sin B = 0.833, so B ≈ 56.4° or 123.6°.
SL 3.6Using the identities without finding θ
Get the missing ratio from cos2 + sin2 = 1, then choose the sign from the quadrant.
Example: cos x = 34, x acute: sin x = √74, sin 2x = 2 × √74 × 34 = 3√78.
SL 3.7Graphs of sin, cos, tan
For a sin(b(x + c)) + d: amplitude |a|, period 2πb (or 360°/b), shift c to the left, principal axis y = d. tan has period π.
Example: y = 3 sin 2x + 1: amplitude 3, period π, maximum 4, minimum −2.
SL 3.8Solving trig equations in an interval
Find the first solution, use symmetry for the second, then add periods until you leave the interval. For sin 2x first double the interval.
Example: 2 sin x = 1, 0 ≤ x ≤ 2π: x = π/6 or 5π/6.

SL 4.1Outliers
An outlier is more than 1.5 × IQR from the nearest quartile. Some outliers are real data, some are errors: say which in context.
Example: Q1 = 10, Q3 = 18, IQR = 8: outliers are below 10 − 12 = −2 or above 18 + 12 = 30.
SL 4.1Data and sampling words
Discrete (counted) or continuous (measured). Sampling: simple random, convenience, systematic (every kth), quota, stratified (in proportion to each group).
Example: Stratified sample of 50 from 600 boys and 400 girls: 50 × 600/1000 = 30 boys and 20 girls.
SL 4.2Reading cumulative frequency and box plots
Median at n/2, Q1 at n/4, Q3 at 3n/4 on the cumulative frequency graph. Mark outliers with a cross. A symmetric box and whiskers suggests the data may be normal.
Example: With 80 values, read the median at a cumulative frequency of 40.
SL 4.3Grouped data
Estimate the mean with mid-interval values. Modal class = class with the highest frequency (equal widths only).
Example: The class 10 ≤ x < 20 uses the mid-interval value 15.
SL 4.3Standard deviation and variance
Found with the GDC only, no formula given. Variance = (standard deviation)2.
Example: Standard deviation 1.5 means variance 1.52 = 2.25.
SL 4.3Changing every data item
Adding c: mean + c, standard deviation unchanged. Multiplying by k: mean × k, standard deviation × k (for positive k).
Example: Mean 12, sd 3. Double then add 5: mean 2 × 12 + 5 = 29, sd 2 × 3 = 6.
SL 4.4Correlation and regression
r from the GDC, −1 ≤ r ≤ 1, only meaningful for linear data. Correlation does not imply causation. The y on x line passes through (x̄, ȳ), predicts y from x only, and extrapolation is unreliable.
Example: For y = 2.5x + 40 (marks against hours): each extra hour adds about 2.5 marks; 40 is the predicted mark for 0 hours.
SL 4.10Regression line of x on y
Use the x on y line (GDC) to predict x from a given y. Do not rearrange the y on x line.
Example: To estimate hours studied from a mark of 70, use the x on y line.
SL 4.5Expected number of occurrences
expected number = n × P(A). It need not be a whole number.
Example: 128 × 0.1 = 12.8 students expected to be absent.
SL 4.6Mutually exclusive, trees, replacement
Mutually exclusive means P(A ∩ B) = 0. "Or" includes both. Multiply along tree branches, add the branches you want. Without replacement the second fraction changes.
Example: Two reds without replacement from 5 red and 3 blue: 58 × 47 = 514.
SL 4.11Testing for independence
Show P(A ∩ B) = P(A)P(B), or P(A | B) = P(A) = P(A | B′). Also P(A ∩ B) = P(B)P(A | B).
Example: P(A) = 0.4, P(B) = 0.5, P(A ∩ B) = 0.2: 0.4 × 0.5 = 0.2, so independent.
SL 4.7Probability distributions
The probabilities add up to 1. E(X) = 0 means a fair game when X is the gain.
Example: P(X = x) = 0.1, 0.2, k, 0.3 gives k = 0.4.
SL 4.8When binomial, and how to use the GDC
Fixed number of trials, two outcomes, constant p, independent trials. pdf for "exactly", cdf for "at most". "At least 3" is 1 − P(X ≤ 2). Standard deviation is √Var(X).
Example: X ~ B(10, 0.3): P(X ≥ 3) = 1 − P(X ≤ 2) ≈ 0.617; sd = √2.1 ≈ 1.45.
SL 4.9Normal distribution facts
About 68% within μ ± σ, 95% within μ ± 2σ, 99.7% within μ ± 3σ. Probabilities and inverse normal values come from the GDC; sketch and shade first.
Example: μ = 50, σ = 5: about 95% of values lie between 40 and 60.
SL 4.12Unknown mean or standard deviation
z is the number of standard deviations from the mean. Get z from inverse normal with mean 0 and sd 1, then put it into the booklet formula.
Example: P(X < 60) = 0.9, σ = 5: z ≈ 1.2816, so μ = 60 − 1.2816 × 5 ≈ 53.6.

SL 5.1, 5.2What the derivative means
Gradient of the tangent and rate of change. f ′(x) > 0: increasing; f ′(x) < 0: decreasing.
Example: f(x) = x2 − 4x: f ′(x) = 2x − 4 > 0 for x > 2, so increasing there.
SL 5.3, 5.6Rewrite as powers first
Turn roots and fractions into powers of x before using the xn rule. A constant multiple stays in front.
Example: y = 3x2 = 3x−2 ⇒ dydx = −6x−3.
SL 5.4Tangents and normals
Tangent gradient m = f ′(a), line through (a, f(a)). Normal gradient −1m.
Example: y = x2 at x = 3: tangent y = 6x − 9, normal y − 9 = −16(x − 3).
SL 5.6Chain rule patterns to recognise
ef(x) → f ′(x)ef(x); ln f(x) → f ′(x)f(x); sin(ax + b) → a cos(ax + b). Only the general chain rule is printed.
Example: y = ex2 + 2 ⇒ dydx = 2x ex2 + 2.
Not SLDerivative of tan x
Not in the SL booklet and not on the SL list (SL 5.6 lists xn, sin, cos, ex, ln). It is HL content (AHL 5.15). If an SL question needs it, write tan x = sin x/cos x (in the booklet, 3.5) and use the quotient rule.
Example: Quotient rule gives 1cos2x, which equals 2 at x = π/4.
SL 5.7, 5.8Stationary points and their nature
Solve f ′(x) = 0. f ″ > 0: minimum (concave-up). f ″ < 0: maximum (concave-down). If f ″ = 0, test the sign of f ′ either side.
Example: y = x3 − 3x: y′ = 3x2 − 3 = 0 at x = ±1; y″ = 6x gives a minimum at (1, −2), a maximum at (−1, 2).
SL 5.8Points of inflexion
f ″(x) = 0 and f ″ changes sign (concavity changes). f ″ = 0 alone is not enough.
Example: y = x4 has y″ = 0 at (0, 0) but no change of sign: it is a minimum, not an inflexion.
SL 5.8Optimisation
Write the quantity in one variable, differentiate, set equal to 0, check it is a maximum or minimum, answer the question asked.
Example: Rectangle with perimeter 20: A = x(10 − x), A′ = 10 − 2x = 0, x = 5, largest area 25.
SL 5.9Velocity and speed
v = dsdt is not printed (only a is). Speed = |v|. At rest when v = 0; changes direction when v changes sign.
Example: s = t3 − 6t2 ⇒ v = 3t2 − 12t, at rest when t = 0 or 4.
SL 5.5Finding the constant C
Integrate, then substitute the given point to find C.
Example: dydx = 3x2 + x, y = 10 at x = 1 ⇒ y = x3 + 12x2 + 8.5.
SL 5.10Integrals of (ax + b) composites
Integrate as usual and divide by a: ∫cos(ax + b) dx = 1asin(ax + b) + C, same for eax+b and 1ax + b.
Example: f ′(x) = cos(2x + 3) ⇒ f(x) = 12sin(2x + 3) + C.
SL 5.10Reverse chain rule (inspection)
If the derivative of the inside bracket is (a multiple of) the factor outside, integrate the bracket as a power.
Example: ∫2x(x2 + 1)4 dx = (x2 + 1)55 + C.
SL 5.11Definite integrals by hand
∫bag ′(x) dx = g(b) − g(a) (no +C).
Example: ∫20(3x2 + 1) dx = [x3 + x]20 = 10.
SL 5.11Areas below the axis and between curves
An integral below the x-axis is negative: split at the roots and add the sizes. Between curves: ∫(top − bottom) dx, which is not printed.
Example: ∫20(x2 − 4) dx = −16/3, so the area is 16/3. Between y = x and y = x2: ∫10(x − x2) dx = 1/6.
