SL 1.2

Arithmetic sequences and series

The pattern: add the same number every time.

By the end of this section I can

The words and the notation

A sequence is an ordered list of numbers called terms. The nth term is written un, so u1 is the first term and n is its position (always a positive integer). A series is what you get when you add terms: Sn means the sum of the first n terms.

A sequence is arithmetic when the difference between consecutive terms is constant. That constant is the common difference d, and it can be negative or a fraction.

Test for arithmetic Learn: u2 − u1 = u3 − u2. Example: 7, 11, 15, 19 has d = 4. Example: 60, 57.5, 55 has d = −2.5.

un = u1 + (n − 1)d In booklet
Sn = n2(2u1 + (n − 1)d)   or   Sn = n2(u1 + un) In booklet

Why it is (n − 1)d and not nd: to get from u1 to u5 you take 4 steps, not 5. Why the sum works: write the series forwards and backwards, and every pair adds to the same total.

Worked example 1: two terms given (pack question 3). The 1st and 5th terms of an arithmetic sequence are 36 and 12. Find u13, then the n for which Sn = 0.
  1. Write u5 with the formula: 36 + 4d = 12.
  2. So 4d = −24 and d = −6.
  3. u13 = 36 + 12 × (−6) = 36 − 72 = −36.
  4. Set the sum to zero: n2(2 × 36 + (n − 1)(−6)) = 0.
  5. n ≠ 0, so 72 − 6n + 6 = 0, which gives 6n = 78 and n = 13.
  6. Sense check: the terms run 36, 30, …, 0, …, −30, −36, symmetric about 0, and u13 = −36, so 13 terms cancel exactly.
Worked example 2: a term and a sum given (pack question 10). u10 = 14 and S25 = 200. Find k such that uk = 0.
  1. From the term: u1 + 9d = 14.
  2. From the sum: 252(2u1 + 24d) = 200, so 2u1 + 24d = 16, so u1 + 12d = 8.
  3. Subtract the first equation from the second: 3d = −6, so d = −2.
  4. Then u1 = 14 − 9 × (−2) = 32.
  5. Solve 32 + (k − 1)(−2) = 0: k − 1 = 16, so k = 17.

Sigma notation

20Σr = 1(3r + 2) means: put r = 1, 2, 3, …, 20 into 3r + 2 and add the results. The number under Σ is where r starts, the number on top is where it stops. Learn the count of terms: top − bottom + 1.

Worked example 3: evaluate a sigma sum without listing. Find 20Σr = 1(3r + 2).
  1. Number of terms: 20 − 1 + 1 = 20.
  2. First term (r = 1): 3 + 2 = 5. Last term (r = 20): 60 + 2 = 62.
  3. It is arithmetic because r goes up by 1 each time, so the terms go up by 3 (d = 3).
  4. S20 = 202(5 + 62) = 10 × 67 = 670.

When you are given Sn instead of un

Learn u1 = S1, and un = Sn − Sn−1. The sum of the first six terms minus the sum of the first five leaves exactly the sixth term.

Worked example 4 (pack question 19). Sn = n² + 4n. Find u1, u6 and a formula for un.
  1. u1 = S1 = 1 + 4 = 5.
  2. S6 = 36 + 24 = 60 and S5 = 25 + 20 = 45, so u6 = 60 − 45 = 15.
  3. From u1 = 5 and u6 = u1 + 5d = 15: 5d = 10, so d = 2.
  4. un = 5 + 2(n − 1) = 2n + 3. Check: n = 6 gives 15.

Applications, including simple interest

Simple interest pays the same amount every year, calculated on the original amount only, so the balance grows arithmetically. In pack question 5, Andy earns 0.315% of $5000 each month: 5000 × 0.00315 = $15.75 a month, which is $189 a year. After n years he has 5000 + 189n dollars: an arithmetic sequence with d = 189.

A model that is not perfectly arithmetic. Real data rarely goes up by exactly the same amount. The guide expects you to approximate the common difference and use it to predict, then say how reliable the prediction is.

Worked example 5: approximate d. A runner's long run in weeks 1 to 5 is 12.1, 13.9, 16.2, 17.8 and 20.0 km. Predict week 10.
  1. The differences are 1.8, 2.3, 1.6 and 2.2: not constant, but close.
  2. Approximate d by the average step: (20.0 − 12.1) ÷ 4 = 7.9 ÷ 4 = 1.975, about 2.0 km per week.
  3. Model: un ≈ 12.1 + 1.975(n − 1).
  4. Week 10: 12.1 + 9 × 1.975 = 29.875, so about 29.9 km.
  5. Comment: week 10 is outside the data (extrapolation), and a runner cannot keep adding 2 km a week for ever, so the prediction is less reliable the further ahead you go.
Exam traps. (1) Writing nd instead of (n − 1)d. (2) Mixing up a term and a sum: "how much in the 13th hour" is u13, "how much in the first 8 hours" is S8. (3) n must be a positive integer: if solving gives n = 21.86 for "how many complete rows can be built", the answer is 21, not 22 (pack question 8(d)); if the question asks when a total first exceeds something, round up. (4) Counting sigma terms as top − bottom instead of top − bottom + 1.

SL 1.3

Geometric sequences and series

The pattern: multiply by the same number every time.

By the end of this section I can

A sequence is geometric when each term is the previous one multiplied by the same common ratio r (r ≠ 0). Test Learn: u2u1 = u3u2. If r is negative the signs alternate: 3, −6, 12, −24 has r = −2.

un = u1rn−1 In booklet
Sn = u1(rn − 1)r − 1 = u1(1 − rn)1 − r, r ≠ 1 In booklet

Both sum formulas give the same answer. Use the first when r > 1 and the second when r < 1, so you work with positive numbers.

Worked example 1: two terms given, then a sum (pack question 30). The volumes of pie slices form a geometric sequence. The 2nd slice is 30 cm³ and the 5th is 240 cm³. The pie is 61 425 cm³. How many slices?
  1. u2 = u1r = 30 and u5 = u1r4 = 240.
  2. Divide: r3 = 240 ÷ 30 = 8, so r = 2. (Dividing two terms removes u1; this is the fastest method.)
  3. u1 = 30 ÷ 2 = 15.
  4. Sum: 15(2n − 1)2 − 1 = 61 425, so 2n − 1 = 4095 and 2n = 4096.
  5. 4096 = 212, so n = 12 slices.
Worked example 2: when does a sum pass a value? (pack question 21, calculator) First term 50, fourth term 86.4. Find the smallest n with Sn > 33 500.
  1. 50r3 = 86.4, so r3 = 1.728 and r = 1.2.
  2. Sn = 50(1.2n − 1)0.2 = 250(1.2n − 1).
  3. Solve 250(1.2n − 1) > 33 500: 1.2n > 135.
  4. With the GDC (table or graph) or logarithms: n > 26.90, and check either side: S26 ≈ 28 369 is too small, S27 ≈ 34 093 is enough.
  5. n = 27. Always give the whole number and show the values either side.
Worked example 3: a negative ratio (pack question 19, parts d and e). A geometric sequence has v2 = 5 and v4 = 15, and v99 < 0. Find r and v5.
  1. v4 = v2r2, so r2 = 3 and r = ±√3. Both are possible until you use more information.
  2. v99 = v2r97. v2 is positive and 97 is odd, so v99 < 0 needs r < 0: r = −√3.
  3. v5 = v4 × r = 15 × (−√3) = −15√3.

Sigma notation and real situations

10Σr = 13(2)r−1 is the geometric series 3 + 6 + 12 + … with 10 terms, first term 3 and ratio 2, so it equals 3(210 − 1)2 − 1 = 3069. If a calculator question gives a sigma sum, identify the first term and the ratio first: the guide says you are expected to.

Growth by a percentage is geometric: grow by 3% means multiply by 1.03; fall by 15% means multiply by 0.85. A town of 12 000 people growing by 2.5% a year has 12 000 × 1.02510 ≈ 15 361 people after 10 years. In year 10 of a list that starts with year 1 at 12 000, the population is 12 000 × 1.0259 ≈ 14 986. Read which one the question means.

Exam traps. (1) Power n instead of n − 1 for un. (2) Taking only the positive root when r2 or r4 is known: r = ±. (3) "At the start of the 10th year" means 9 complete years have passed (pack question 2(d) wants S9; using n = 10 loses most of the marks). (4) 1.03n for "after n years" but 1.03n−1 for "in year n" when year 1 is the starting value.

SL 1.8 (taught together with geometric sequences)

Sum to infinity

How can infinitely many numbers add up to something finite?

By the end of this section I can

If −1 < r < 1, the powers rn get closer and closer to 0 as n grows. So in Sn = u1(1 − rn)1 − r the rn disappears, and the series has a finite total: it converges. If |r| ≥ 1 the terms do not shrink, and there is no sum to infinity.

S∞ = u11 − r,   |r| < 1 In booklet

|r| is the modulus of r: its size without the sign. |r| < 1 means the same as −1 < r < 1.

Worked example 1: sigma starting at r = 1 (pack question 26). Find ∞Σr = 123(78)r.
  1. First term: put r = 1, so u1 = 23 × 78 = 1424 = 712. It is not 23.
  2. Ratio: r = 78, and |78| < 1, so the sum exists.
  3. S∞ = 7/121 − 7/8 = 712 × 8 = 5612 = 143.
Worked example 2: the bouncing ball in the banner (pack question 9). A ball is dropped from 10 m and each bounce reaches 23 of the previous height. Find the total distance travelled.
  1. The ball falls 10 m once. After that, every peak is travelled twice: up and down.
  2. The peaks are 10 × 23 = 203, then 409, and so on: geometric with u1 = 203 and r = 23.
  3. Sum of the peaks: 20/31 − 2/3 = 203 × 3 = 20 m.
  4. Total: 10 + 2 × 20 = 50 m. For a drop from x metres the same steps give 5x, which is part (c) of the pack question.
Worked example 3: when does the sum exist? For which x does 1 + 2x + 4x2 + … have a sum to infinity? Find the sum when x = 14.
  1. Ratio: r = 2x1 = 2x.
  2. Condition: |2x| < 1, so |x| < 12, that is −12 < x < 12.
  3. x = 14 is inside, r = 12, so S∞ = 11 − 1/2 = 2.
Exam traps. (1) Using S∞ without checking |r| < 1: always write the check, it is often a mark. (2) Wrong first term when the sigma has a power r instead of r − 1, as in (78)r (worked example 1): put r = 1 to find u1. (3) Bouncing-ball questions: the first drop is counted once, every later height twice. (4) Dividing by r or by 1 + r instead of 1 − r.
Self-check SL 1.8
  1. Find S∞ for 12 + 8 + 163 + …
  2. Does 2 − 4 + 8 − … have a sum to infinity? Why?
  3. A geometric series has S∞ = 40 and r = 34. Find u1.

Answers. 1: r = 23, S∞ = 121/3 = 36. 2: no; r = −2 and |−2| = 2 is not less than 1, so the terms grow. 3: 40 = u11/4, so u1 = 10.

SL 1.4

Financial applications: compound interest and depreciation

Money that grows or shrinks by a percentage is a geometric sequence.

By the end of this section I can

FV = PV × (1 + r100k)kn In booklet

FV is the future value, PV the present value, n the number of years, k the number of compounding periods per year (1 yearly, 2 half-yearly, 4 quarterly, 12 monthly), r% the nominal annual interest rate.

value after n years = original × (1 − r100)n Learn

Depreciation is the same idea with a decrease: this is the booklet formula with k = 1 and −r in place of r. The guide says exam questions will not ask you to derive the formula, and may expect the GDC financial app.

Worked example 1: yearly compounding (pack question 5(b)). Jess invests $5000 at 3% compounded annually. Find the value after 5 years and the interest earned.
  1. PV = 5000, r = 3, k = 1, n = 5.
  2. FV = 5000 × (1 + 3100)5 = 5000 × 1.035 = 5796.37…
  3. To the nearest dollar: $5796. Interest = 5796.37 − 5000 = $796.
Worked example 2: monthly compounding (pack question 17). Sorin invests $160 000 at a nominal 5% a year, compounded monthly. Find the value after 6 months.
  1. k = 12, so each month multiplies by 1 + 51200.
  2. After n years: 160 000 × (1 + 51200)12n. Six months is n = 0.5, so the power is 12 × 0.5 = 6.
  3. 160 000 × (1 + 51200)6 = $164 041.89 to two decimal places.
  4. On the GDC financial app: N = 0.5 (years), I% = 5, PV = −160 000, PMT = 0, P/Y = 1, C/Y = 12, solve FV. PV and FV must have opposite signs (money paid in is negative).
Worked example 3: depreciation in two stages (pack question 15). A car bought for $35 000 loses 15% in the first year, then 11% in each later year. Find its value 10 years after purchase.
  1. End of year 1: 35 000 × 0.85 = $29 750.
  2. Ten years after purchase means nine more years at 11%: multiply by 0.89 nine times, not ten.
  3. 29 750 × 0.899 = 10 423.10…, so $10 423 to the nearest dollar.
  4. Part (c), less than 10% of the original ($3500): solve 29 750 × 0.89n−1 < 3500 with a table. n = 19 gives $3651.80, n = 20 gives $3250.10, so n = 20.
Worked example 4: find the rate (pack question 17(d)). $30 000 grows to $41 000 in six years with interest compounded quarterly. Find r.
  1. 30 000 × (1 + r400)24 = 41 000 (k = 4, kn = 24).
  2. Solve with the GDC (solver or financial app): r = 5.2403…
  3. r = 5.24% to two decimal places, as the question asks.

Real value and inflation

Inflation means prices rise, so the same amount of money buys less. The real value of an investment is what it is worth in today's prices.

Worked example 5. $1000 is invested for 10 years at 5% compounded yearly. Inflation is 2% a year. Find the real value.
  1. Nominal value: 1000 × 1.0510 = $1628.89.
  2. Remove 10 years of 2% inflation: 1628.89 ÷ 1.0210 = $1336.26 in today's money.
  3. Quick method many textbooks and mark schemes use: real rate ≈ 5% − 2% = 3%, so 1000 × 1.0310 = $1343.92. Use the method your teacher showed and say which one you used.
Exam traps. (1) Wrong k or forgetting to multiply n by k: monthly for 3 years is a power of 36. (2) "After 10 years" counted from the wrong starting value, as in worked example 3. (3) Rounding money too early or to the wrong accuracy: the first answer given to the wrong number of decimal places loses a mark (pack question 17's note). (4) GDC: PV and FV with the same sign gives an error or a nonsense answer.

  2. Gemma earns $45 000 in 2011 and gets 2% more on 1 January each year. Find her 2021 salary to the nearest dollar. (pack question 24(a))
  3. A laptop bought for $2000 depreciates by 20% a year. Find its value after 3 years.

SL 1.6

Simple deductive proof

A proof shows something is true for every case, not just the cases you tried.

By the end of this section I can

Equality and identity

= (equals) is true for some values: x + 2 = 5 only when x = 3. ≡ (is identical to) is true for every value of the variable: (x + 1)2 ≡ x2 + 2x + 1 for all x. Most "show that" algebra questions are identities. Learn the symbol and when to use it.

How to lay out an LHS to RHS proof

  1. Start with one side only, usually the more complicated one.
  2. Change it one step at a time with algebra you can justify (expand, factorise, common denominator).
  3. Stop when you reach exactly the other side. Write "= RHS" and a short concluding sentence.

Never start from the statement you are trying to prove and work on both sides at once: that assumes the answer.

Worked example 1: the guide's own example. Show that (x − 3)2 + 5 ≡ x2 − 6x + 14.
LHS = (x − 3)2 + 5
    = x2 − 6x + 9 + 5expand the bracket
    = x2 − 6x + 14 = RHScollect terms
Check, as the guide asks: put x = 0. LHS = 9 + 5 = 14 and RHS = 14. A check is not a proof, but it catches slips.
Worked example 2: numerical, then algebraic (also from the guide). Show that 14 + 112 = 13, then that 1m + 1 + 1m2 + m ≡ 1m.
LHS = 14 + 112 = 312 + 112common denominator
    = 412 = 13 = RHS
LHS = 1m + 1 + 1m(m + 1)factorise m2 + m
    = mm(m + 1) + 1m(m + 1)common denominator
    = m + 1m(m + 1) = 1m = RHScancel m + 1
With m = 3 this is exactly the numerical line. It holds for every m except 0 and −1, where a denominator would be zero (proof pack Easy 2(a)(ii) and Hard 5(b) ask you to state such cases).
Worked example 3: a statement about all integers (proof pack Medium 4). Prove that the sum of any three consecutive integers is divisible by 3.
  1. Let the integers be n, n + 1 and n + 2, where n is any integer. (Letters, not examples: 4 + 5 + 6 = 15 proves nothing about other cases.)
  2. Sum = n + (n + 1) + (n + 2) = 3n + 3.
  3. = 3(n + 1).
  4. n + 1 is an integer, so the sum is 3 times an integer: divisible by 3.
Useful forms Learn: an even integer is 2k, an odd integer is 2k + 1. For two different odd numbers use different letters, 2a + 1 and 2b + 1.
Worked example 4: proof inside a sequences question (sequences pack question 1). The first three terms of an arithmetic sequence are u1, 5u1 − 8 and 3u1 + 8. Show that u1 = 4, then prove that Sn is always a square number.
  1. Equal differences: (5u1 − 8) − u1 = (3u1 + 8) − (5u1 − 8).
  2. 4u1 − 8 = −2u1 + 16, so 6u1 = 24 and u1 = 4.
  3. The terms are 4, 12, 20, so d = 8.
  4. Sn = n2(2 × 4 + 8(n − 1)) = n2(8n) = 4n2 = (2n)2.
  5. 2n is an integer, so Sn is a square number. The mark scheme gives the last mark only for saying why 4n2 is a square.
Worked example 5: always positive (proof pack Medium 2). Show that x2 − 3x + 3 > 0 for all x.
  1. Complete the square: x2 − 3x + 3 = (x − 32)2 − 94 + 3 = (x − 32)2 + 34.
  2. A square is never negative: (x − 32)2 ≥ 0.
  3. So the expression is at least 34, which is greater than 0, for every x.
Exam traps. (1) Testing a few numbers instead of using letters: examples are a check, never a proof. (2) Working on both sides at once, or starting from the statement to be proved. (3) Using the same letter for two different numbers (2n + 1 and 2n + 1 are the same odd number). (4) Stopping at "= 3n + 3" without the final sentence: the conclusion line is often the last mark. (5) Writing = when the question wants ≡, or the other way round.
Self-check SL 1.6
  1. Show that (a − b)2 − (a + b)2 ≡ −4ab. (proof pack Medium 3)
  2. Prove that the square of any even integer is divisible by 4. (proof pack Medium 5)
  3. Prove that the sum of any three consecutive even integers is divisible by 6. (proof pack Medium 15)
  4. Prove that the product of any two odd integers is odd. (proof pack Hard 2)

Answers. 1: LHS = a2 − 2ab + b2 − (a2 + 2ab + b2) = −4ab = RHS. 2: (2k)2 = 4k2, and k2 is an integer, so it is divisible by 4. 3: 2n + (2n + 2) + (2n + 4) = 6n + 6 = 6(n + 1), and n + 1 is an integer. 4: (2a + 1)(2b + 1) = 4ab + 2a + 2b + 1 = 2(2ab + a + b) + 1, which is 2 times an integer plus 1, so odd.
