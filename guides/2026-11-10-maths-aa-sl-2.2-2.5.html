SL 2.2 (school 2.3 and 2.5)

Functions, domain, range and the idea of an inverse

A function is a rule that gives every allowed input exactly one output.

By the end of this section I can

The words and the notation

A function takes each input x from its domain and gives exactly one output f(x). The set of all outputs is the range. f(3) means "put 3 in": if f(x) = x2 + 1 then f(3) = 10. The letters change with the context: v(t) is a velocity at time t, C(n) a cost for n items. The graph of f is every point (x, f(x)).

Domain and range

In an exam the domain is the largest possible domain unless the question gives one. For today's functions there are two things that are not allowed Learn (logarithms add a third later in Topic 2):

  • dividing by zero: f(x) = 1x − 5 needs x ≠ 5;
  • the square root of a negative number: √(x + 3) needs x + 3 ≥ 0, so x ≥ −3.

Write the domain with x (x ≥ −3) and the range with f(x) or y (f(x) ≥ 0). Interval notation is also accepted Learn: [a, b] includes both ends, ]a, b[ includes neither, so x ≥ 1 is [1, ∞[ and 2 < x < 5 is ]2, 5[.

Worked example 1: the guide's own example. Find the largest possible domain and the range of f(x) = √(2 − x).
  1. The expression under the root cannot be negative: 2 − x ≥ 0.
  2. So x ≤ 2. Check one value either side: f(1) = √1 = 1 works; f(3) = √(−1) does not exist.
  3. A square root is never negative, and f(2) = √0 = 0, so the smallest output is 0.
  4. As x goes down (f(−2) = 2, f(−7) = 3), the output keeps growing without limit, so the range is f(x) ≥ 0.
Worked example 2: a domain that is given (pack Medium 4). f(x) = −6x − 3 for −5 ≤ x ≤ 3. Find f(2), the x with f(x) = 15, the range of f and the domain of f−1.
  1. f(2) = −6 × 2 − 3 = −15.
  2. −6x − 3 = 15, so −6x = 18 and x = −3. It is inside the domain, so it counts.
  3. The graph is a straight line with a negative gradient, so the outputs run between the values at the two ends: f(−5) = 30 − 3 = 27 and f(3) = −18 − 3 = −21.
  4. Both ends are included (≤), so the range is −21 ≤ f(x) ≤ 27, smallest value first.
  5. The domain of f−1 is the range of f: −21 ≤ x ≤ 27.

A function as a model

Worked example 3 (pack Hard 1). A square with side x has perimeter P = 4x and area A = x2. Write P in terms of A and A in terms of P. Then, given that P−1(40) = A(k), find k.
  1. From A = x2: x = √A (a length is positive). So P = 4√A.
  2. From P = 4x: x = P4. So A = P216.
  3. P−1(40) is the area that gives a perimeter of 40: 4√A = 40, so √A = 10 and A = 100.
  4. A(k) = k216 = 100, so k2 = 1600 and k = 40 (a perimeter is positive, so not −40).
  5. Why the answer is 40 again: A(P) undoes P(A), so P−1 is the function A. That is what an inverse is.

The inverse function: undo, and reflect in y = x

f(x) = 2x + 3 means "double, then add 3". To undo it, do the opposite operations in the opposite order: "subtract 3, then halve", so f−1(x) = x − 32. f(4) = 11 and f−1(11) = 4.

The guide's example Learn: solving f(x) = 10 is the same as finding f−1(10). Here 2x + 3 = 10 gives x = 3.5, and f−1(10) = 10 − 32 = 3.5. You do not need the whole inverse to find one value of it.

Inputs and outputs swap, so every point (a, b) on y = f(x) becomes (b, a) on y = f−1(x). Swapping the coordinates is a reflection in the line y = x Learn: look at the banner, where (3, 7) on f matches (7, 3) on f−1. The same swap gives Learn: domain of f−1 = range of f, and range of f−1 = domain of f.

An inverse exists only for a one-to-one function. f(x) = x2 on all real numbers has f(−2) = f(2) = 4, so "undo 4" has two answers and there is no inverse. Restrict the domain to x ≥ 0 and the inverse is √x.

Exam traps. (1) Writing the range with x ("x ≥ 0"): the mark scheme does not accept it. (2) Strict or not, for a straight-line function: if the domain has <, the matching end of the range has < too; if it has ≤, keep ≤. (3) Range of a decreasing function: put the smaller value first, −21 ≤ f(x) ≤ 27, not 27 ≤ f(x) ≤ −21. (4) f−1(x) is not 1f(x). (5) Forgetting that a solution must lie in the domain.

SL 2.3 (school 2.3)

The graph of a function

A graph is the function drawn: every point on it is an input and its output.

By the end of this section I can

The point (a, b) lies on the graph of y = f(x) exactly when f(a) = b. Example: (3, 5) is on y = x2 − 4 because 9 − 4 = 5; (1, 2) is not, because 1 − 4 = −3.

Draw or sketch? Learn

Command termWhat the IB means
DrawAn accurate, labelled graph in pencil: to scale, points plotted correctly, a ruler for straight lines, joined by a straight line or a smooth curve.
SketchThe general shape, labelled as appropriate, with the relevant features. Not to scale, but the features must be in the right places.

A sketch must still show Learn: labelled axes; intercepts with their coordinates; maximum and minimum points; asymptotes as dashed lines with their equations; end points if the domain is restricted (solid dot if included, open dot if not); and the right shape at both ends. When you copy a graph from the GDC screen to paper, note the window you used and read the key points with the GDC tools (zero, minimum, maximum, intersect) before you copy.

Worked example 1: a sketch from information. A quadratic function has zeros at x = −1 and x = 3 and a maximum point at (1, 4). Find f(x) and sketch y = f(x).
  1. Zeros at −1 and 3 mean f(x) = a(x + 1)⁠(x − 3) for some a.
  2. Use the maximum: f(1) = a(2)⁠(−2) = −4a = 4, so a = −1.
  3. f(x) = −(x + 1)⁠(x − 3) = −x2 + 2x + 3. The y-intercept is f(0) = 3.
  4. a < 0, so the parabola opens downwards. Mark and label (−1, 0), (3, 0), (0, 3) and (1, 4), and draw a smooth curve symmetric about x = 1.

Sums and differences of functions

(f + g)⁠(x) means f(x) + g(x): at each x, add the two heights. (f − g)⁠(x) = f(x) − g(x). On the GDC, enter f in Y1 and g in Y2, then Y3 = Y1 − Y2.

Key features of graphs and intersections

What to look for on any graph, and how to find where two graphs meet.

By the end of this section I can

The key features Learn

FeatureHow to find it
y-interceptPut x = 0. Give the point (0, f(0)).
Zeros, roots, x-interceptsThe same x-values, three names: solve f(x) = 0. As points they are (x, 0).
Vertex, maximum or minimumFor a quadratic the vertex is on the axis of symmetry x = −b2a In booklet. The maximum or minimum value is the y-coordinate.
SymmetryA parabola is symmetric about its axis. A graph can also be symmetric about the y-axis, for example y = x2: it has the same height at x and at −x. (The names "odd" and "even" function are HL only, AHL 2.14.)
Vertical asymptoteA line x = a that the graph approaches but never reaches; usually where a denominator is zero.

Worked example 1: all the features of a quadratic. f(x) = x2 − 2x − 3.
  1. y-intercept: f(0) = −3, the point (0, −3).
  2. Zeros: x2 − 2x − 3 = (x − 3)⁠(x + 1) = 0, so x = 3 or x = −1.
  3. Axis of symmetry: x = −−22 × 1 = 1 (halfway between the zeros, as a check).
  4. Vertex: f(1) = 1 − 2 − 3 = −4, so (1, −4). a > 0, so it is a minimum and the minimum value is −4.
  5. Range: f(x) ≥ −4.

Intersections

Two graphs meet where they have the same y for the same x, so solve f(x) = g(x) Learn, then find y from either equation. On Paper 2 use the GDC: graph both and use the intersect tool (TI-84 Plus CE: 2nd, TRACE (CALC), 5: intersect; Casio fx-CG50: G-SOLV, then ISCT). Give answers to 3 significant figures unless they are exact.

Worked example 2: where a line meets the parabola. Find the points where y = x2 − 2x − 3 meets y = x + 1.
  1. Set equal: x2 − 2x − 3 = x + 1.
  2. Collect on one side: x2 − 3x − 4 = 0, so (x − 4)⁠(x + 1) = 0.
  3. x = 4 or x = −1.
  4. Find y from the line (easier): x = 4 gives y = 5; x = −1 gives y = 0.
  5. The points are (4, 5) and (−1, 0). Check in the parabola: 16 − 8 − 3 = 5 and 1 + 2 − 3 = 0.

Asymptotes

Worked example 3: asymptotes and intercepts. f(x) = 1 + 3x − 2. Find the asymptotes and the axis intercepts.
  1. x − 2 = 0 at x = 2, where f is not defined: vertical asymptote x = 2.
  2. When x is very large (positive or negative), 3x − 2 gets close to 0, so f(x) gets close to 1: horizontal asymptote y = 1.
  3. y-intercept: f(0) = 1 + 3−2 = −0.5, the point (0, −0.5).
  4. Zero: 3x − 2 = −1, so x − 2 = −3 and x = −1, the point (−1, 0).
  5. So the domain is x ≠ 2 and the range is f(x) ≠ 1. On the GDC you see the same: the graph runs along the dashed lines without touching them.
Exam traps. (1) Giving "x = 4" when the question asks for the point: write (4, 5). (2) The minimum value is the y-coordinate (−4), not the x where it happens. (3) Asymptotes are lines, so write equations: "x = 2", not "2". (4) Finding the x-values of an intersection and stopping: you need the y-values too. (5) GDC answers rounded too early or to fewer than 3 significant figures.
Self-check SL 2.4

  2. f(x) = −2x2 + 8x − 3. Find the axis of symmetry, the vertex, the y-intercept and the range.
  3. Write down the asymptotes of y = 4 − 3x.
  4. Find the points of intersection of y = 2x + 1 and y = x2 − 2.

Answers. 1: x2 − 4x + 3 = (x − 1)⁠(x − 3) = 0, so x = 1 or 3: the line crosses the parabola at x = 1 and x = 3. 2: x = −8−4 = 2; f(2) = −8 + 16 − 3 = 5, so the vertex is the maximum (2, 5); y-intercept (0, −3); range f(x) ≤ 5. 3: x = 0 and y = 4. 4: x2 − 2x − 3 = 0, x = 3 or −1, points (3, 7) and (−1, −1).

Composite functions and finding the inverse

Functions can be chained, and a function chained with its inverse does nothing at all.

By the end of this section I can

Composite functions

(f ∘ g)⁠(x) = f(g(x)) Learn

Read it from the inside out: g acts first, then f acts on g's output. The function written next to x goes first.

Worked example 1: both orders. f(x) = 3x − 1 and g(x) = x2 + 2. Find (f ∘ g)⁠(x) and (g ∘ f)⁠(x), and check with x = 2.
  1. (f ∘ g)⁠(x) = f(x2 + 2): replace every x in f with x2 + 2.
  2. = 3(x2 + 2) − 1 = 3x2 + 5. Check: 3 × 4 + 5 = 17, as in the picture.
  3. (g ∘ f)⁠(x) = g(3x − 1) = (3x − 1)2 + 2.
  4. = 9x2 − 6x + 1 + 2 = 9x2 − 6x + 3. Check: 36 − 12 + 3 = 27.

Domain of a composite: g's output must be an allowed input for f. With f(x) = √x and g(x) = x − 4, (f ∘ g)⁠(x) = √(x − 4) only exists for x ≥ 4.

The identity function and the inverse

(f ∘ f−1)⁠(x) = (f−1 ∘ f)⁠(x) = x Learn

The function x ↦ x is the identity function: it changes nothing. A function followed by its inverse (in either order) is the identity. This is also the quickest check of an inverse you have found.

Worked example 2: show two functions are inverses (pack Medium 2). f(x) = 12⁠(4x − 3) and g(x) = 0.5x + 0.75. Find (f ∘ g)⁠(x) and (g ∘ f)⁠(x), and hence write down f−1(x).
  1. (f ∘ g)⁠(x) = 12⁠(4(0.5x + 0.75) − 3) = 12⁠(2x + 3 − 3) = x.
  2. (g ∘ f)⁠(x) = 0.5 × 12⁠(4x − 3) + 0.75 = x − 0.75 + 0.75 = x.
  3. Both orders give the identity, so g undoes f: f−1(x) = 0.5x + 0.75.
  4. f is linear on all real numbers, so its range is all real numbers: domain of f−1 is x ∈ ℝ, and its range is ℝ too.

Finding f−1(x) in four steps Learn

  1. Write y = f(x).
  2. Swap x and y.
  3. Rearrange to make y the subject.
  4. Write f−1(x) = … and state its domain, which is the range of f.
Worked example 3: a linear function. f(x) = 2x + 53. Find f−1(x).
  1. y = 2x + 53.
  2. Swap: x = 2y + 53.
  3. 3x = 2y + 5, so 2y = 3x − 5 and y = 3x − 52.
  4. f−1(x) = 3x − 52, x ∈ ℝ. Check: f−1(4) = 72 and f(72) = 7 + 53 = 4.
Worked example 4: the banner, a restricted domain. f(x) = (x − 1)2 + 3 for x ≥ 1. Find f−1(x) and its domain.
  1. Why the restriction: on all real numbers f(0) = f(2) = 4, so f is not one-to-one. For x ≥ 1 only the right half of the parabola is used, which is one-to-one. At SL the question gives you the restricted domain; choosing a restriction yourself is HL (AHL 2.14).
  2. Range of f: (x − 1)2 ≥ 0, so f(x) ≥ 3.
  3. y = (x − 1)2 + 3. Swap: x = (y − 1)2 + 3.
  4. (y − 1)2 = x − 3, so y − 1 = ±√(x − 3).
  5. Choose the sign: the range of f−1 is the domain of f, y ≥ 1, so take +.
  6. f−1(x) = 1 + √(x − 3), for x ≥ 3. Check: f(3) = 7 and f−1(7) = 1 + 2 = 3.
Worked example 5: find f when you know f ∘ g (pack Hard 5). Write x2 + 12x + 24 in the form (x + h)2 + k. Then, with g(x) = x + 6 and (f ∘ g)⁠(x) = x2 + 12x + 24, find f(x).
  1. Complete the square: x2 + 12x + 24 = (x + 6)2 − 36 + 24 = (x + 6)2 − 12.
  2. (f ∘ g)⁠(x) = f(x + 6), so f(x + 6) = (x + 6)2 − 12.
  3. f squares its input and subtracts 12: f(x) = x2 − 12.
Exam traps. (1) Doing the composite in the wrong order: in (f ∘ g)⁠(x), g goes first. (2) Writing ± in the final inverse: choose one sign using the domain (pack Hard 4 gives no mark for ±). (3) Forgetting the domain of f−1: it is the range of f, not the domain of f. (4) Swapping x and y but then not rearranging fully. (5) Reading f−1(x) as 1f(x).
Self-check SL 2.5
  1. f(x) = x2 and g(x) = 4x − 3. Find (f ∘ g)⁠(x) and (g ∘ f)⁠(x). (pack Medium 1(b))
  2. f(x) = √(x − 14) for x ≥ 14, and g is a function with an inverse and g(14) = 3. Find (f ∘ g−1)⁠(3). (pack Hard 2(b))
  3. h(x) = −4x2 + 24x + 8. Write h(x) as a(x − p)2 + q. With f(x) = (x − 3)2 and (g ∘ f)⁠(x) = h(x), find g(x). (pack Hard 9)
  4. Find the inverse of f(x) = 5 − 2x.

Answers. 1: (f ∘ g)⁠(x) = (4x − 3)2 = 16x2 − 24x + 9; (g ∘ f)⁠(x) = 4x2 − 3. 2: g(14) = 3 means g−1(3) = 14, so the answer is f(14) = √0 = 0. 3: h(x) = −4(x − 3)2 + 44, so g takes (x − 3)2 to −4(x − 3)2 + 44: g(x) = −4x + 44. 4: x = 5 − 2y, so y = 5 − x2: f−1(x) = 5 − x2.

Ten questions, Paper 1 style (no calculator)

Quick quiz

Work each one out on paper first, then click your answer. Every question explains the trap after you answer. Write any you miss into the Error log.

1. The largest possible domain of f(x) = √(5 − x) is

5 − x ≥ 0 gives x ≤ 5. x < 5 wrongly leaves out x = 5, where f(5) = √0 = 0 is fine. x ≥ 5 comes from not flipping the sign when dividing by −1. x ≥ 0 mixes the domain up with the range, which is f(x) ≥ 0.

2. The point (k, 7) lies on the graph of y = 2x2 − 1, with k > 0. The value of k is

Put x = k and y = 7: 2k2 − 1 = 7, so k2 = 4 and k = 2 (k > 0). 4 is k2, not k; √3 comes from subtracting 1 instead of adding it; 97 is the y-value at x = 7, which swaps the coordinates.

3. f(x) = 2x + 1. The value of f−1(9) is

f−1(9) is the input that f sends to 9: 2x + 1 = 9 gives x = 4. 19 is f(9); 119 treats f−1 as a reciprocal; 5 is 9 + 12, which undoes "+ 1" with another "+ 1".

4. f(x) = x + 5 and g(x) = x2. The value of (f ∘ g)⁠(3) is

g acts first: g(3) = 9, then f(9) = 14. 64 is (g ∘ f)⁠(3) = 82, the wrong order. 17 is f(3) + g(3) and 72 is f(3) × g(3): a composite is neither a sum nor a product.

5. f(x) = x − 23. f−1(x) is

Swap: x = y − 23, so 3x = y − 2 and y = 3x + 2. Check: f(3 × 1 + 2) = f(5) = 1. 3x − 2 undoes the division but not the subtraction; 3x − 2 is the reciprocal of f; x + 23 undoes the subtraction but divides again.

6. The graphs of y = x2 and y = x + 6 meet at

x2 = x + 6 gives x2 − x − 6 = (x − 3)⁠(x + 2) = 0, so x = 3 or −2, and y = x + 6 gives 9 and 4. (−3, 9) and (2, 4) come from the wrong signs in the brackets; check: −3 + 6 = 3, not 9. (3, 0) and (−2, 0) forget to find y. "(3, 9) only" drops the negative solution.

7. The graph of y = 2 + 1x + 3 has asymptotes

The denominator is zero at x = −3, so x = −3 is vertical. For very large x the fraction tends to 0, so y tends to 2: y = 2 is horizontal. x = 3 has the wrong sign; y = 0 forgets the "2 +"; the last option swaps x and y.

8. The vertex of y = 2x2 − 8x + 1 is

Axis: x = −b2a = 84 = 2 (in the booklet). y = 2 × 4 − 16 + 1 = −7. (−2, 25) drops the minus in −b; (2, −11) forgets to multiply x2 by 2; (4, 1) uses −ba instead of −b2a.

9. Which of these functions has an inverse function?

Only one-to-one functions have inverses. x2 for x ≥ 0 is one-to-one. x2 on ℝ has f(−2) = f(2); x2 − 4x for x ≥ 0 has f(0) = f(4) = 0 (its vertex is at x = 2, inside the domain); a constant function sends every input to 5.

10. f(x) = √(x − 1) + 2 for x ≥ 1. The domain of f−1 is

The domain of f−1 is the range of f. The root is at least 0 (at x = 1), so f(x) ≥ 2. x ≥ 1 is the domain of f, which becomes the range of f−1; x ≥ 0 forgets the "+ 2".
