Coordinates and reading a graph

A graph has two number lines: the x-axis going across and the y-axis going up. They cross at the point (0, 0). A point is written (x, y): first go across, then up. (3, 7) is 3 right and 7 up; (−2, 4) is 2 left and 4 up.

For a function, the y-value is the output. The point (a, b) is on the graph of y = f(x) exactly when f(a) = b. So when the page says read the domain off the x-axis, it means: which x-values does the graph use? Read the range off the y-axis means: which y-values (heights) does the graph reach?

When a question says write down the coordinates of a point on a graph, you read them off the graph or the given information, with little or no working.

Straight lines: y = mx + c

Every straight line that is not vertical has an equation y = mx + c.

  • m is the gradient: how much y changes when x goes up by 1. Through two points, m = (y2 − y1) ÷ (x2 − x1).
  • c is where the line crosses the y-axis, at the point (0, c).

Example: through (0, −4) and (3, 8), m = 12 ÷ 3 = 4 and c = −4, so y = 4x − 4. A negative m means the line goes down from left to right. A horizontal line has the equation y = b and a vertical line x = a. A function whose graph is a straight line is called linear.

Putting numbers into a formula

For f(x) = x2 + 1, f(3) means: put 3 in place of x. So f(3) = 32 + 1 = 10.

Put negative numbers in brackets: f(−2) = (−2)2 + 1 = 4 + 1 = 5, because a negative times a negative is positive. Careful: −x2 at x = 3 means −(32) = −9, not 9. The square is done before the minus.

Order of work: brackets first, then powers, then × and ÷, then + and −. So 2 × 4 − 16 + 1 = 8 − 16 + 1 = −7.

Solving and rearranging equations

An equation stays true if you do the same thing to both sides. To solve it, undo what was done to x, in reverse order:

2x + 3 = 10 → subtract 3 from both sides: 2x = 7 → divide both sides by 2: x = 3.5.

Rearranging works the same way when there are only letters. To get y on its own in x = (2y + 5) ÷ 3:

  • multiply both sides by 3: 3x = 2y + 5;
  • subtract 5: 3x − 5 = 2y;
  • divide by 2: y = (3x − 5) ÷ 2.

This is exactly how you will find an inverse function today.

Inequalities and the number line

  • < less than, ≤ less than or equal to
  • > greater than, ≥ greater than or equal to
  • ≠ not equal to

x ≥ −3 means every number from −3 upwards, including −3 itself. 2 < x < 5 means every number between 2 and 5, but not 2 or 5.

Solve an inequality like an equation, with one extra rule: when you multiply or divide both sides by a negative number, flip the sign. 2 − x ≥ 0 → −x ≥ −2 → divide by −1 and flip: x ≤ 2.

On a number line or graph, a solid dot means the end is included (≤, ≥) and an open dot means it is not (<, >).

Square roots and dividing by zero

√9 = 3, because 3 × 3 = 9. The √ sign always means the positive root (or 0), so a square root is never negative. But the equation x2 = 9 has two answers, 3 and −3, written x = ±3.

A negative number has no square root on the number line: √(−1) does not exist, because any number times itself is 0 or positive.

The reciprocal of a number is 1 divided by it: the reciprocal of 4 is 1/4. You cannot divide by zero, so 1/0 does not exist.

These two facts (no square root of a negative, no dividing by zero) decide almost every domain on this page.

Expanding brackets and factorising quadratics

Expanding: multiply every part of one bracket by every part of the other. (x − 3)(x + 1) = x2 + x − 3x − 3 = x2 − 2x − 3.

Factorising goes backwards. For x2 − 2x − 3, find two numbers that multiply to −3 and add to −2: they are −3 and 1. So x2 − 2x − 3 = (x − 3)(x + 1).

To solve (x − 3)(x + 1) = 0: if two numbers multiply to 0, one of them must be 0, so x = 3 or x = −1.

Squaring a bracket: (x − 1)2 = (x − 1)(x − 1) = x2 − 2x + 1, not x2 + 1.

The Khan Academy page uses American words: factor means factorise, and a binomial is a bracket with two parts, like (x + 1).

Functions, domain, range and the idea of an inverse

A function is a rule that gives every allowed input exactly one output.

By the end of this section I can

The words and the notation

A function takes each input x from its domain and gives exactly one output f(x). The set of all outputs is the range. f(3) means "put 3 in": if f(x) = x2 + 1 then f(3) = 10. The letters follow the context: v(t) is a velocity at time t, C(n) a cost for n items. The graph of f is every point (x, f(x)).

Domain and range

In an exam the domain is the largest possible domain unless the question gives one. Two things are not allowed today Learn: dividing by zero (1x − 5 needs x ≠ 5) and the square root of a negative number (√(x + 3) needs x ≥ −3). Write the domain with x and the range with f(x) or y. Interval notation is also accepted: [a, b] includes both ends, ]a, b[ neither, so x ≥ 1 is [1, ∞[.

Worked example 1: the guide's own example. Find the largest possible domain and the range of f(x) = √(2 − x).
  1. Under the root: 2 − x ≥ 0, so x ≤ 2.
  2. A square root is never negative, and f(2) = 0 is the smallest output.
  3. As x goes down (f(−2) = 2, f(−7) = 3) the output grows without limit: range f(x) ≥ 0.
Why this step? Why does x get smaller in step 3, not bigger?

The domain is x ≤ 2, so the only way to move is to the left.

Worked example 2: a given domain (pack Medium 4). f(x) = −6x − 3 for −5 ≤ x ≤ 3. Find f(2), the x with f(x) = 15, the range of f and the domain of f−1.
  1. f(2) = −15. −6x − 3 = 15 gives x = −3, inside the domain.
  2. A straight line: the outputs run between the end values f(−5) = 27 and f(3) = −21.
  3. Both ends included: range −21 ≤ f(x) ≤ 27, smallest first. Domain of f−1 = range of f: −21 ≤ x ≤ 27.
Why this step? Why only the two end values?

A straight line has no turning point, so its highest and lowest values are at the ends of the domain.

  1. Straight line, so use the ends: f(−2) = −7 (included) and f(3) = 13 (not included).

A function as a model

In pack Hard 1 a square with side x has perimeter P = 4x and area A = x2. As functions of each other: P = 4√A and A = P216 (a length is positive, so only +√). Each one undoes the other: they are inverse functions.

The inverse function: undo, and reflect in y = x

f(x) = 2x + 3 means "double, then add 3". Undo it with the opposite operations in the opposite order: "subtract 3, then halve", so f−1(x) = x − 32. The guide's example Learn: solving f(x) = 10 is the same as finding f−1(10): 2x + 3 = 10 gives 3.5, and f−1(10) = 3.5.

Inputs and outputs swap, so (a, b) on f becomes (b, a) on f−1: a reflection in the line y = x Learn (the banner shows (3, 7) and (7, 3)). So domain of f−1 = range of f Learn. An inverse exists only for a one-to-one function: x2 on all real numbers has f(−2) = f(2) = 4, so no inverse; on x ≥ 0 the inverse is √x.

Exam traps. (1) Writing the range with x: no mark. (2) A < in the domain gives a < at that end of the range. (3) Smaller value first: −21 ≤ f(x) ≤ 27. (4) f−1(x) is not 1f(x). (5) A solution must lie in the domain.

The graph of a function

A graph is the function drawn: every point on it is an input and its output.

By the end of this section I can

(a, b) lies on y = f(x) exactly when f(a) = b: (3, 5) is on y = x2 − 4 because 9 − 4 = 5.

Draw or sketch? Learn Draw: accurate, to scale, points plotted, ruler for straight lines. Sketch: the general shape with the relevant features in the right places, not to scale. A sketch still needs: labelled axes; intercepts with coordinates; maximum and minimum points; asymptotes as dashed lines with equations; end points of a restricted domain (solid dot if included, open if not). Copying from the GDC: read the key points with its tools (zero, minimum, maximum, intersect) first.

Worked example 1: a sketch from information. A quadratic has zeros at x = −1 and x = 3 and a maximum at (1, 4). Find f(x) and sketch it.
  1. Zeros at −1 and 3: f(x) = a(x + 1)⁠(x − 3).
  2. f(1) = a(2)⁠(−2) = −4a = 4, so a = −1 and f(x) = −x2 + 2x + 3; y-intercept 3.
  3. a < 0: opens downwards. Label (−1, 0), (3, 0), (0, 3) and (1, 4).
Why this step? Why use the point (1, 4) in step 2?

The zeros fix the brackets but not the number a in front; one more point on the curve fixes a.

Sums and differences of functions

(f + g)⁠(x) = f(x) + g(x) and (f − g)⁠(x) = f(x) − g(x): at each x, add or subtract the heights. On the GDC: f in Y1, g in Y2, then Y3 = Y1 − Y2.

Worked example 2. f(x) = x2 and g(x) = 2x. Sketch f − g with f and g.
  1. (f − g)⁠(x) = x2 − 2x: zeros at 0 and 2, minimum (1, −1).
  2. f − g is zero exactly where f and g are equal: the graphs cross at x = 0 and x = 2.
Why this step? Why is f − g zero where the graphs cross?

There the two heights are equal, and equal heights subtract to 0.

Exam traps. (1) A sketch without labelled intercepts or turning points loses marks. (2) Drawing past the end of a restricted domain. (3) A GDC window that hides a feature: zoom out once. (4) Asymptotes solid or without equations.

It is halfway between the zeros −1 and 3, because a parabola is symmetric.

Intersections

Two graphs meet where they have the same y for the same x: solve f(x) = g(x) Learn, then find y. On Paper 2 use the GDC intersect tool (as in your class GDC guide: TI-Nspire CX: Menu, 6: Analyze Graph, 4: Intersection; Casio fx-CG50: SHIFT F5 (G-Solv), F5 (INTSECT)), answers to 3 significant figures unless exact.

Asymptotes

Worked example 3. f(x) = 1 + 3x − 2. Find the asymptotes and intercepts.

The identity function and the inverse

x ↦ x is the identity function: it changes nothing. (f ∘ f−1)⁠(x) = (f−1 ∘ f)⁠(x) = x Learn. In pack Medium 2, f(x) = 12⁠(4x − 3) and g(x) = 0.5x + 0.75 give (f ∘ g)⁠(x) = (g ∘ f)⁠(x) = x, so g is f−1. This is also the quickest check of an inverse.

Finding f−1(x) in four steps Learn

(1) Write y = f(x). (2) Swap x and y. (3) Rearrange to make y the subject. (4) Write f−1(x) = … and state its domain, the range of f.

Worked example 2: linear. f(x) = 2x + 53.
  1. Swap: x = 2y + 53, so 3x = 2y + 5 and y = 3x − 52.
  2. f−1(x) = 3x − 52, x ∈ ℝ. Check: f−1(4) = 3.5 and f(3.5) = 4.
Why this step? Why swap x and y?

The inverse sends outputs back to inputs, so the roles of x and y change places.

Worked example 3: the banner, a restricted domain. f(x) = (x − 1)2 + 3 for x ≥ 1. Find f−1(x) and its domain.
  1. x ≥ 1 keeps only the right half of the parabola, which is one-to-one. Range of f: f(x) ≥ 3.
  2. Swap: x = (y − 1)2 + 3, so y − 1 = ±√(x − 3).
  3. The range of f−1 is the domain of f, y ≥ 1, so take +: f−1(x) = 1 + √(x − 3), x ≥ 3. Check: f(3) = 7 and f−1(7) = 3.
Why this step? Why the + sign?

The outputs of f−1 must be at least 1; 1 − √(x − 3) would give values below 1.

Worked example 4 (pack Hard 5). g(x) = x + 6 and (f ∘ g)⁠(x) = x2 + 12x + 24. Find f(x).
  1. Complete the square: x2 + 12x + 24 = (x + 6)2 − 12.
  2. f(x + 6) = (x + 6)2 − 12: f squares its input and subtracts 12, so f(x) = x2 − 12.
Why this step? Why complete the square first?

It writes the answer in terms of x + 6, which is exactly what g feeds into f.

Exam traps. (1) Wrong order: in (f ∘ g)⁠(x), g goes first. (2) ± left in the final inverse (pack Hard 4 gives no mark for it). (3) Domain of f−1 is the range of f. (4) Not rearranging fully after the swap.

1. The largest possible domain of f(x) = √(5 − x) is

5 − x ≥ 0 gives x ≤ 5. x < 5 leaves out x = 5, where f(5) = 0 is fine. x ≥ 5 forgets to flip the sign when dividing by −1. x ≥ 0 mixes the domain up with the range.

2. The point (k, 7) lies on the graph of y = 2x2 − 1, with k > 0. The value of k is

2k2 − 1 = 7, so k2 = 4 and k = 2. 4 is k2; √3 subtracts 1 instead of adding it; 97 swaps the coordinates.

3. f(x) = 2x + 1. The value of f−1(9) is

f−1(9) is the input that f sends to 9: 2x + 1 = 9 gives 4. 19 is f(9); 119 treats f−1 as a reciprocal; 5 undoes "+ 1" with another "+ 1".

4. f(x) = x + 5 and g(x) = x2. The value of (f ∘ g)⁠(3) is

g first: g(3) = 9, then f(9) = 14. 64 is the wrong order, (g ∘ f)⁠(3). 17 and 72 are f(3) + g(3) and f(3) × g(3).

5. The graphs of y = x2 and y = x + 6 meet at

x2 − x − 6 = (x − 3)⁠(x + 2) = 0, so x = 3 or −2, with y = 9 and 4. The first option has the wrong signs (−3 + 6 = 3, not 9); (3, 0) and (−2, 0) forget y; "only" drops a solution.

6. The graph of y = 2 + 1x + 3 has asymptotes

The denominator is zero at x = −3; for very large x the fraction tends to 0, so y tends to 2. x = 3 has the wrong sign; y = 0 forgets the "2 +"; the last option swaps x and y.
